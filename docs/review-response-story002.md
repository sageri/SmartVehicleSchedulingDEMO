### 問題4: 到着・出発時間計算エラー ✅ 修正完了

**指摘内容:**
> 時間コールバックで既に service_time を加算しているため、CumulVar(index) は離開時間を表す。しかし _extract_routes では arrival_minutes として扱い、departure_minutes で再度 service_time を加算し、全時間戳が1〜2サービス時間分遅延する。

**問題の詳細分析:**

```python
# vrp_service.py:258-261（時間コールバック）
if to_node > 0:  # 拠点以外
    service_time = deliveries[to_node - 1].service_time
    return travel_time + service_time  # 弧権重に service_time 含む
```

この実装により：
- **CumulVar(index) の意味:** 配送点での**離開時間**（到着 + サービス）
- **従来の誤り:** arrival = CumulVar, departure = CumulVar + service_time
- **実際の影響:** 全時刻が15分（サービス時間）〜30分遅れて表示

**修正内容:**

**ファイル:** `backend/app/services/vrp_service.py`
**行:** 397-401

```python
# 修正前（誤り）
arrival_minutes = solution.Min(time_var)
departure_minutes = solution.Min(time_var) + delivery.service_time

# 修正後（正解）
departure_minutes = solution.Min(time_var)
arrival_minutes = departure_minutes - delivery.service_time
```

**修正理由:**
1. ✅ **CumulVar = 離開時間** - コールバックで service_time 既加算
2. ✅ **到着時間 = 離開 - サービス** - 逆算で正確な到着時刻
3. ✅ **Demo 信頼性向上** - 時間窓表示が正確になる
4. ✅ **修正コスト極小** - 2行のみ変更

**検証方法:**

**シナリオ:** 8:00 出発 → 30分移動 → 配送点到着 → 15分サービス → 出発

| 項目 | 値 | 説明 |
|-----|---|------|
| OR-Tools CumulVar | 45分 | 移動30分 + サービス15分 = 8:45（離開時刻） |
| **修正前（誤り）** | | |
| arrival_time | 8:45 | ❌ 実際は8:30のはず（15分遅延） |
| departure_time | 9:00 | ❌ 実際は8:45のはず（15分遅延） |
| **修正後（正解）** | | |
| departure_minutes | 45 | ✅ CumulVarそのまま使用 |
| arrival_minutes | 30 | ✅ 45 - 15 = 30 |
| arrival_time | 8:30 | ✅ 正確 |
| departure_time | 8:45 | ✅ 正確 |

**影響範囲:**
- ✅ 全ルート結果の時間戳が正確化
- ✅ 時間窓制約（morning/afternoon）の表示が正しくなる
- ✅ フロントエンド地図UIでの停靠時間表示が正確化
